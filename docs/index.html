斐波那契回调（当前策略） 多级别（10分/30分/1时/2时/3时/6时）：MACD 金叉 → 高点死叉 = 一段上涨；回调到再次金叉/底分型时，回撤 ≤50% 即有效
① 上涨段：最近一次 MACD 金叉 → 之后的 死叉（高点），拉斐波那契（高点=0%，起点=100%）
② 回调段：死叉之后的下跌，到 再次金叉 或 底分型第三根收盘 为止
③ 回撤比例 =（高点 − 回调最低）÷ 前段涨幅；≤「最大回撤%」即视为有效，立刻提醒
实测：六个级别一起看时，50% 口径约 18 条、61.8% 约 25 条、78.6% 约 40 条（181 标的快照）。
顶部结构（已停用） 级别 15分/30分/1时/2时/3时/6时 · 五根形态 + 第5根新低预警 → 反包确认
五根K线的形态（级别：15分 / 30分 / 1时 / 2时 / 3时 / 6时）：
  第1根 = 这段高点；第2根不创新高（高点 ≤ 第1根），收盘形态随意；
  第3根形态随意，但高点不超第1根；第4根形态随意，但高点不超第2根；
  第5根价格低于前四根（创这段新低）。
收盘确认（默认，不提前提醒）：
  • 五根形态成立后出现反转点（创新低收阳 / 阳包阴）
  • 之后等到某一根收盘同时站上 MA7 与 EMA7 → 结构确认提醒（与三根K线底分型确认是不同事件）
  • 底部结构为镜像：收盘同时跌破 MA7 与 EMA7 才确认

若勾选「提前预警」：
  • 第5根创新低 → 预警（先提示）
  • 之后任一根反包（阳包阴） → 确认提醒（要求与前一根有止跌反包关系）
  • 若第6根又创新低，则第7根不创新低时预警，第7根反包则确认 —— 可一直跌到第 N 根
  • 一直创新低时不提醒（还在跌）；价格重新站上第1根高点则结构失效
两级五浪（当前策略） 主级别回调 ≥5 根 → 次级别 下上下上下 五笔→ 主级别底分型成立即报
① 主级别（15分/30分/1时/2时/3时/6时）：回调 高点→之后最低点 ≥5 根K线。
② 次级别（3分/5分/10分/15分/30分/1时）：高低点连成 下上下上下 五笔，一笔一浪，每笔至少5根K线（含首尾）。
③ 回调最低点就是底分型中间那根，第三根收盘成立 → 提前提醒；只使用该确认时刻已收盘的数据，同一结构仅提醒一次。
同一段回调优先选最大的有效五浪级别，再等配对主级别确认。15分和30分都合格时，采用30分→3时。
某笔只有4根时可向小一档复核，复核仍须每笔≥5根；例如10分降为5分后，改等30分底分型。MACD不作为条件。
